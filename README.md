# Programming Fundamentals - Lab 4 Solutions

This repository contains C programming solutions for **Lab 4**, focusing on foundational programming concepts, conditional decision-making, and input handling.

## 🛠️ Key Concepts Covered
* **Control Structures:** Conditional statements (`if`, `if-else`, nested `if-else`)
* **Logical & Relational Operators:** Logical OR (`||`), AND (`&&`), and relational comparisons
* **Input/Output Handling:** `scanf()`, string input using `fgets()`, character parsing, and string output using `puts()`
* **Arithmetic Operations:** Temperature conversion, rectangle calculations, powers (square/cube), and averaging
